# Social brand glyphs

TikTok, WhatsApp, Instagram SVG glyphs sourced from Simple Icons (CC0), downloaded
from the maintained develop branch on 2026-10-07. These are third-party
reproductions of brand marks, not a certification of the latest official assets.

Source: https://github.com/simple-icons/simple-icons
License: https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md
Brand guidance: https://www.meta.com/brand/resources/ and
https://developers.tiktok.com/doc/getting-started-design-guidelines

Google uses the existing multicolor GoogleMark component. There is no invented
separate Google Review logo.
